# Academic Homepage

This is a single-file GitHub Pages homepage for a mathematics PhD candidate.
The live site is deployed at `https://flypde.github.io`.

## Edit

Most content lives in `index.html`. Search and replace:

- `Your Name`
- `University Name`
- `your.email@example.com`
- `Advisor Name` if you add your advisor line
- publication titles, talks, teaching entries, and academic links

The page is intentionally self-contained: CSS, JavaScript, and the mathematical
SVG visual are all inline in `index.html`. This avoids GitHub Pages asset
publishing issues and makes the homepage easy to move.

## Suggested academic links

- CV PDF
- Google Scholar
- ORCID
- arXiv author page
- GitHub
- department profile

## Deploy

This repository currently publishes from the `gh-pages` branch. After editing
`index.html`, commit and push the change to `gh-pages`; GitHub Pages will update
`https://flypde.github.io` after the Pages deployment finishes.
